Poly Pen is a fork of Nanum Pen Script. It is a Modified Version of Nanum Pen Script under the SIL Open Font License 1.1, not an original typeface. Outlines start from Nanum Pen Script. Each glyph is faceted into triangles, then touching faces are merged into one outline.

Coverage matches the source font, including Korean Hangul and the rest of the Nanum Pen Script character map. The family name is Poly Pen. It does not use the reserved names Nanum or NanumPen. Styles: Thin 100 through Black 900.
