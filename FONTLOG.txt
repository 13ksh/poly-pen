and any derivative works.


Basic Font Information
----------------------------------------------------------------------

Poly Pen is a fork of Nanum Pen Script (SIL Open Font License 1.1
Modified Version). It is not an original typeface family. Outlines
start from Nanum Pen Script, then each glyph is faceted into triangles.
Touching faces are merged into one outline so connected strokes stay
one part.

The family name is "Poly Pen". It does not use the reserved names
Nanum or NanumPen.

Styles: Regular 400 and Bold 700. Bold is a stroke expansion of the
same faceted outlines so apps that request weight 700 keep this family.

Coverage matches Nanum Pen Script, including the full Hangul syllable
block and the rest of the source cmap.
