Poly Pen

Nanum Pen Script 포크. zFont 3 · One UI 8용 TTF입니다. 삼성에서 “지원하지 않는 글꼴 / 공급업체에 문의”가 뜨면 이 페이지에서 파일을 다시 받으세요. 이름표를 삼성 로더 형식에 맞춰 고쳤습니다.

zFont 3 · One UI 8

Play 스토어의 zFont 3에 이 TTF를 넣은 뒤, 적용 화면에서 One UI 8을 고르면 됩니다. 패키지 만들 때 zFile 설치를 물어보면 같이 설치합니다.

zFont용 TTF 받기 ZIP (ttf + 설치) zFont 3 (Play)

파일 확인 중…

  1. zFont 3 설치
  2. 여기의 PolyPen-Regular.ttf 다운로드
  3. zFont → Downloads에서 이 ttf 선택 → 체크
  4. One UI 8 선택 → Create
  5. zFile 설치 요청이 나오면 설치한 뒤 다시 Create
  6. Install Package → 설정 → 디스플레이 → Font size and style에서 Poly Pen
