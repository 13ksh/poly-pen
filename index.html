zFont 3 · One UI 8

Play 스토어의 zFont 3에 Regular와 Bold TTF를 같이 넣은 뒤, 적용 화면에서 One UI 8을 고르면 됩니다. 패키지 만들 때 zFile 설치를 물어보면 같이 설치합니다.

Regular TTF Bold TTF ZIP (두 두께 + 설치) zFont 3 (Play)

파일 확인 중…

  1. zFont 3 설치
  2. 여기의 PolyPen-Regular.ttf와 PolyPen-Bold.ttf 다운로드
  3. zFont → Downloads에서 Regular 선택, Bold도 같이 넣기
  4. One UI 8 선택 → Create
  5. zFile 설치 요청이 나오면 설치한 뒤 다시 Create
  6. Install Package → 설정 → 디스플레이 → Font size and style에서 Poly Pen
