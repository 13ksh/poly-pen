# Trademarks and reserved names

Poly Pen is a fork of Nanum Pen Script. It is an independent Modified
Version and is not affiliated with, endorsed by, or sponsored by NHN,
Naver, or Sandoll.

Nanum Pen Script carries Reserved Font Names including **Nanum** and
**NanumPen**. Poly Pen does not use those names as its family name,
file names, or PostScript names.

Do not describe Poly Pen as “Nanum Pen Script” in product UI. Describe
it as a Nanum Pen Script fork, or as Poly Pen derived from Nanum Pen
Script.
